# 🛍️ smart-store | متجر المنتجات الذكي

تطبيق ويب بسيط وعملي لإدارة المنتجات، مصمم بأسلوب متجر حقيقي مع دعم رفع الصور وتوليد **QR Code** لكل منتج يعرض سعره وتفاصيله بمجرد مسحه بكاميرا الهاتف المحمول.

---

## 🏷️ معلومات المستودع (GitHub Info)
- **اسم المشروع على GitHub (Repository Name):** `smart-store`
- **الوصف (Description):** نظام إدارة المنتجات الذكي مع رفع الصور وتوليد باركود QR للأسعار بتقنية PHP و MySQL.

---

## ✨ المميزات الرئيسية
- 📋 **عرض المنتجات**: جدول أنيق يعرض اسم المنتج، صورته، سعره، والـ QR الخاص به.
- 🖼️ **رفع الصور**: إمكانية رفع صورة للمنتج وحفظها على السيرفر تلقائياً.
- 📱 **QR Code تفاعلي**: لكل منتج كود QR خاص، عند مسحه بكاميرا الجوال يظهر اسم المنتج وسعره فوراً.
- ✏️ **تعديل السعر**: إمكانية تحديث سعر أي منتج بسهولة.
- 🗑️ **حذف المنتج**: إمكانية حذف المنتج مع مسح صورته المرفقة من السيرفر تلقائياً لتوفير المساحة.
- ☕ **تصميم دافئ ومريح**: ألوان ترابية دافئة وهادئة تمنح شعور المتجر الحقيقي وتريح العين أثناء الاستخدام.
- ⚡ **تثبيت ذاتي**: يتم إنشاء قاعدة البيانات والجدول تلقائياً بمجرد فتح الصفحة لأول مرة!

---

  ```
  http://localhost/phpmyadmin
  ```
